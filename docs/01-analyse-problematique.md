# Phase 1 — Analyse de la problématique

## Présentation du besoin

MediBook est une application web de réservation de rendez-vous médicaux en ligne.

Elle permet aux patients de trouver un médecin disponible, de consulter ses informations principales et de réserver un rendez-vous depuis une interface simple.

## Contexte

La prise de rendez-vous médicaux peut être longue et peu pratique.  
Les patients doivent souvent appeler plusieurs cabinets pour connaître les disponibilités, tandis que les médecins doivent gérer leurs rendez-vous manuellement.

MediBook propose une solution centralisée pour simplifier cette organisation.

## Utilisateurs

L’application est destinée à trois types d’utilisateurs :

- Patient
- Médecin
- Administrateur

## Objectifs métier

Les objectifs métier sont :

- faciliter la prise de rendez-vous médicaux ;
- centraliser les médecins disponibles ;
- permettre aux patients de gérer leurs rendez-vous ;
- sécuriser l’accès aux données avec une authentification ;
- distinguer les droits selon les rôles utilisateurs.

## Fonctionnalités principales

- Création de compte patient
- Connexion sécurisée
- Consultation des médecins
- Réservation de rendez-vous
- Consultation des rendez-vous
- Annulation de rendez-vous
- Gestion des rôles utilisateurs
